# Performance - measured on this port

All numbers below were produced by the scripts in this repository on the
development container used for this release (Dart 3.14.1, x64) and are
reproducible:

```sh
cd packages/liquid_glass_core
dart test                  # 41 unit tests
dart run tool/dump_profile.dart   # writes tool/profile.json + prints the table
python3 ../../scripts/crosscheck_optics.py   # independent math cross-check
```

## Optics constants (default config: T = 20, B = 26, n = 1.5, M = 22)

| Quantity | Value |
| --- | --- |
| `Delta_max` (exact trace) | **3.8166 px** |
| peak position `s` | **0.1311** (strictly inside the bezel: clear center, bent rim) |
| rim limit `sqrt(1-eta^2)/eta` | 1.118034 (finite - the rim stays continuous) |
| LUT build (512 exact Snell evaluations) | **~30 us** |
| 4 same-optics elements | 1 build + **3 cache hits**, 1 live LUT |

## Band-limited raster (CPU encoder path)

The CPU encoder (parity/export/debug path) touches only the bezel band -
`~perimeter x B` pixels instead of `w x h`, with the odd mirror writing up
to four pixels per evaluation:

| Element | Full-res pixels | Band pixels written | Ratio | Raster time |
| --- | --- | --- | --- | --- |
| 522 x 621 panel, r = 28, B = 26 | 324,162 | 56,072 | **x5.8 fewer** | 23.3 ms |
| 522 x 621 panel, r = 28, B = 10 | 324,162 | 22,072 | **x14.7 fewer** | 10.9 ms |
| 353 x 163 card, r = 26, B = 26 | 57,539 | 23,552 | **x2.4 fewer** | 5.2 ms |
| 480 x 64 capsule toolbar, B = 26 | 30,720 | 24,748 | x1.2 (near-dome - physically correct: `B = 26` of a 32 half-height is nearly the full dome) | 5.2 ms |

The narrow-bezel case shows the geometry of the claim: the band is
`perimeter x B`, so the saving scales linearly with how small the bezel is
relative to the element.

**The Flutter GPU path does not rasterize any map at all** - the encoder
numbers exist to prove parity with the original 8-bit pipeline and to
service the debug preview widget.

## 8-bit encoding bound (CPU parity path)

* map values: `Delta/Delta_max` in `[-1, 1]` over the full `0..255` range;
  neutral level 128 decodes to exactly 0;
* loss-minimizing scale `S = 2M = 44 px` => quantization step
  `S/255 = 0.1725 px` (the spec's "~0.17 px at M = 22");
* worst-case measured error of the dithered encoder: within
  `1/127.5` normalized (half LSB of quantization + half LSB of ordered
  dither), asserted by unit test;
* the GPU path skips quantization entirely (float uniforms) - effective
  step **0 px**, strictly better than the bound that justified the original
  "lowest possible quality loss" claim.

## GPU cost model (per element, per frame)

* exactly **one** `BackdropFilter` layer - its filter *is* the shader
  (displacement + frost + saturation + rim lighting in a single pass;
  no dual "edge frost" layer, no separate lighting layers);
* texture taps per fragment: **1** (no CA, no frost), **3** (with CA),
  **up to 7** (CA + frost) - all local, cache-friendly;
* per-frame Dart work: 19 `setFloat` uniform writes and an `ImageFilter`
  handle creation; **zero** per-pixel Dart work, zero LUT upload, zero
  texture allocation;
* attribute-only updates: `refractionStrength`, `chromaticAberration`,
  `frost`, `saturation`, `lightAngleDeg`, `rim`, `tint` never rebuild the
  LUT, re-encode a map, or invalidate the lens layer (watch
  `LiquidGlassEngine.metrics.lutBuilds` while dragging sliders in the
  demo - it does not move);
* LUT rebuilds happen only when `(T, B_effective, n)` changes - and cost
  ~30 us, shared refcount-free across all same-optics elements.

## Fallback cost (soft mode)

One `BackdropFilter` blur + one painted rim layer (sweep gradient), no
shader, no LUT - the same "blur + saturate + lighting layers" fallback the
web engine ships for engines without the refraction path.

## Independent cross-check

`tool/profile.json` (generated by `dart run tool/dump_profile.dart`) is
re-verified by an independent pure-Python implementation of the spec
(`scripts/crosscheck_optics.py`): every LUT entry agrees at Float32
precision (worst deviation `5.6e-8`, i.e. the storage format's epsilon),
`Delta_max`, the peak position, the finite rim ratio, `Delta(0) = Delta(1) =
0` and the cache-sharing invariants all match.
